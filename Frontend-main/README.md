# ⚔️ Frontend Battle - UI/UX Showcase

A modern, fully responsive frontend challenge project using **React**, **TailwindCSS**, and animations powered by **Framer Motion** and **Lottie**. Built to showcase smooth UI/UX interactions, animations, and theme toggling.

---

## 🔥 Features

- 🌗 Light/Dark mode toggle
- 💡 Glowing background effects
- ✨ Parallax scroll section
- 💧 Interactive ripple effect
- 🧮 Animated counter
- 📦 Interactive grid layout
- ⌨️ AI-typewriter text animation
- 💬 Testimonials section
- 📋 Timeline steps with transitions
- 📱 Fully responsive design
- 🚀 Deployed on Netlify

---

## 📂 Folder Structure

/src
├── assets/ # Lottie JSONs & images
├── components/ # Navbar, Loader, ScrollToTop, etc.
├── pages/ # Parallax, Counter, Ripple, Grid, etc.
├── sections/ # Hero, Features, Steps, Testimonials, Contact, Footer
└── App.jsx # Main router layout

## 🧑‍💻 Setup & Installation

```bash
# Clone the repo
git clone https://github.com/Shreya04-bot/Frontend.git
cd Frontend

# Install dependencies
npm install

# Run development server
npm run dev

Then open http://localhost:5173/
